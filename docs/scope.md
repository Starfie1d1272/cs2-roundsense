# RoundSense — Scope

> 状态：v0.1 研究基线（2026-08-06 收敛）。本文件固定"当前做什么、明确不做什么"。

## 1. 项目定位

面向 **CS2 普通玩家**（非观战/非赛事制作）的**只读实时决策辅助研究项目**。
不是通用 HUD、不是直播工具、不是 OBS 套件、不是游戏内 Overlay。

能力目标：

1. **P0-A**：普通玩家状态下 C4 安放事件读取与剩余时间估算精度。
2. **P0-B**：基于个人经济、装备与下一回合目标的目标约束型购买建议。
3. **P1**：`cs2-demo-format` v3 ZIP 真值分析（离线验证经济/C4 规则）。

## 2. 数据来源边界（唯一允许的信号源）

| 来源 | 用途 | 状态 |
|---|---|---|
| GSI（本地 HTTP POST，127.0.0.1） | 实时决策输入 | P0-A/P0-B 输入 |
| `cs2-demo-format` v3 ZIP（本地） | 真值分析、离线验证 | P1 |
| Windows 受控实验（本地服务器 + demo/GSI） | 未决规则实测 | 待执行（协议见 docs/experiments/） |

## 3. 当前不做什么（明确排除）

- 不做通用 HUD / Overlay / 直播 / OBS 集成。
- 不读取/修改游戏内存，不注入，不模拟输入。
- 不根据职业语料修改正式 loss-bonus 状态机（语料只用于确认，不驱动修改）。
- 不在同一语料上选择并报告模型精度（训练/验证必须按比赛划分）。
- 不把 3400 封顶 payout 等同于精确内部状态（上限建模为区间 [4, ∞)）。
- 不猜 unknown 武器击杀奖励（显式报错）。
- 不为每个残差值新建一次性脚本（统一走唯一 validator）。
- 不在实验完成前宣称 GSI 字段/规则实测结论（runtime-unverified 必须保持未验证）。
